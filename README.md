# SecureShop

SecureShop es una empresa ficticia de comercio electrónico que requiere una plataforma web para la gestión de usuarios, productos y pedidos. El sistema implementa una arquitectura basada en **microservicios**, con servicios y bases de datos independientes para cada dominio y un punto de entrada común.

Además del desarrollo funcional, se consideran aspectos de **seguridad de software**. Incluyendo activos, amenazas, y controles para dichas amenazas.
